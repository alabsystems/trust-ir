# Level slice: link + run + value-check (trust-ir -> trust-cg -> native)

Drives the 34 **first-party** clean-kernel `Level` functions all the way through
the real backend and checks that each computes the correct value.

```
frontend --mir-emit-closure   ->  self-contained textual trust-ir module
  -> trust-ir convert (text->bin) + tMBC envelope  -> .tmbc
  -> trust-cg -c  (built from jump-table-fix branch e4455fb)  -> Mach-O .o
  -> link (closure object[s] + runtime.o + Rust driver)  ->  run
  -> structurally compare every result to the REAL Rust method (oracle)
```

`./build_and_run.sh [outdir]` regenerates everything from scratch.

## Result: 33 / 34 run correctly

`--mir-emit-closure <fn>` pulls every crate-local callee (all `Level` methods,
derived `Clone`/`PartialEq`/`Hash`, and closure combinators like
`unwrap_or_else`) INTO one self-contained module. The only external leaves are
the monomorphized **std generics** the corpus imports by mangled name. Those are
NOT heap-primitives-only (contra the original premise): they are `Box::new`,
`<Box<Level> as Clone>::clone`, `HashMap::{new,get,insert}` + `drop_in_place`,
`Option::{map,is_none}`, `<u32>::saturating_add`, `Range<u32>::{into_iter,next}`,
the `core::cmp::impls` `&Name`/`&Level`/`&Box<Level>` `PartialEq::eq` forwarders,
`Vec::<Name>::push`, `<u32|isize as Hash>::hash::<DefaultHasher>`, and `abort`.

`runtime.c` supplies those leaves (real semantics; the `HashMap` memo is a
correctness-preserving always-miss stub whose `insert` frees the moved key).
The two `Hash` leaves are supplied in `driver.rs` in Rust, forwarding to the
real `DefaultHasher::write_*` so SipHash matches std exactly.

| group | binary links | fns value-checked | result |
|-------|--------------|-------------------|--------|
| main  | substitute.o + has_params.o + collect_params.o + param.o + runtime.o | 30 (+ closure#0..3 via substitute) | 87/87 PASS |

(Three "family" binaries because `substitute`/`is_def_eq`/`leq` each drag the
shared `is_geq` sub-closure and so cannot co-reside without duplicate symbols.)

## The one failure: `Level::hash` — a trust-cg codegen bug

The derived `Hash for Level` hashes the discriminant first:
`Hash::hash(&sext_i32(tag), state)` via `<isize as Hash>::hash::<DefaultHasher>`.
The emitted trust-ir is correct (`call func.1(%disc_temp, %state)`), but the
trust-cg **assembly** passes the wrong pointer:

```
sub  x0, x29, #0x30    ; x0 = &disc_temp
sxtw x2, w1            ; x2 = sext(tag)
str  x2, [x0]          ; disc_temp = sext(tag)   (correct)
mov  x1, x20           ; arg1 = state
mov  x0, x9            ; arg0 = x9 = SELF pointer  <-- BUG (should stay &disc_temp)
bl   <isize-hash-leaf>
```

So the discriminant-hash leaf receives `&self` (an aggregate ptr) instead of the
scalar `&disc_temp`. `Name::hash` (structurally identical but hashing a real
field pointer `self+4`) is fine, which isolates the fault to *passing the address
of a freshly-materialized scalar temp*. Proof: a compensating leaf that reads the
tag from the self-ptr trust-cg wrongly passes makes all 8 hash cases pass — i.e.
the frontend IR and the runtime are both correct; only trust-cg mis-lowers the
argument. **Bucket: trust-cg codegen gap** (branch `fix/jumptable-blockarg-edge-encode`,
e4455fb), not a frontend gap and not a runtime-model choice.

## Runtime soundness (ASan + leaks)

- **ASan**: clean over 200 iterations of the Box/HashMap-memo/Vec/Range paths
  (no OOB / use-after-free / double-free).
- **Leaks**: the runtime's own alloc/free is balanced (pure `add_offset` path =
  **0 leaks**). The ~140 KB leaked in the mixed harness is a *separate trust-cg
  characteristic*: no `free`/`__rust_dealloc`/`drop_in_place::<Level>` primitive
  is emitted or referenced by any closure object, so every `Level` the compiled
  code drops internally (e.g. `max` discarding its losing branch,
  `normalize`/`is_geq` discarding intermediates) leaks. This does not affect
  computed values.

## Files
- `runtime.c`      — the 15 std-generic leaves (exact Mach-O mangled symbols).
- `driver.rs`      — value-check driver (real-method oracle via a `mod oracle`
  copy of the corpus) + the two Rust `Hash` leaves; built once per `--cfg grp_*`.
- `oracle.rs`      — generated by the build script (corpus, methods `pub`, no `main`).
- `asan_harness.c` — C harness for the ASan / `leaks` runs.
- `build_and_run.sh` — regenerates and runs the whole pipeline.
