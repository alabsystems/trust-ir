# MiniRust U64 function / SemR correspondence

The new theorem executes the existing generated MiniRust function entry, two private stack allocations, argument initialization, frame push, and the actual Assign/Return scheduler steps. It connects every admitted result to the canonical SemR u64 addition result, with a complete returned caller machine. It does not add an evaluator or compiler admission interface.

`MiniRustU64Correspondence.full_tree_exact` equates the original operations with their complete four-choice tree. Both allocation filters, both scheduler choices, rejected branches and operation errors remain in the equation. `function_correspondence` handles every input and literal strictly below 2^64 and arbitrary remaining model fields in the stated single-thread caller domain. The caller return slot must contain exactly eight bytes at an eight-byte-aligned address.

`original_function_correspondence` consumes the complete unchanged 262-byte wire-v38 compiler Module through the real decoder and `runFunction`. Its SHA256 is `9f6b6822cbe02635dab8a34293e2dfdc590071993d3c06e4611acd0897eb5be8`. The subject returns input+7 modulo 2^64. `original_canonical_no_bad` separately proves the canonical relational `BodyViolation` exclusion; `original_model_no_error` excludes generated-model errors at admitted leaves. Neither statement licenses a Rust body.

`EveryResult` treats a rejected branch as no result, rather than successful execution. Non-vacuity is independent: `full_function_available` constructs an actual oracle under an explicit sufficient high-water/strict-end room condition. It is not a claim that this condition is necessary. The inhabited control has an existing outside allocation, a caller slot, fresh private addresses 32/40, and proves all-u64 availability; maximum-u64 input returns 6. An invalid scheduler choice actually rejects.

The endpoint retains the outside allocation records, both dead private allocation records and their payloads, the updated caller return bytes, caller continuation/PC, all unaffected base fields, and the actual final accesses. Existing access history is reset by the real `Machine.step`; this theorem does not preserve that old log. The caller's future execution and wholeprogram initial reachability are outside this function boundary.

The generated model is byte-identical to the existing canonical model, with its fixed x86_64 layout dictionary. The MiniRust function AST is explicit model data. Rust source/TCX-to-Core fidelity, source population, general cross-model allocation/memory refinement, Tree Borrows, physical Rust ABI/ISA, SourceNoUB, body licensing and proof grades remain open. Canonical SemR `runFunction` begins with `Mem.empty`; the separate arbitrary-SemR-memory `run` theorem must not be confused with that entry.

The maintained Core wrapper has its independently qualified step-projection link. Its continuing result retains the complete machine; its terminal result intentionally discards the machine. The present function theorem does not claim wholeprogram `Machine.new` initialization or Core reachability.

The proof uses no new axioms. Standard imported Lean assumptions are `propext`, `Classical.choice` and `Quot.sound`. Fresh same-Lean replay checks the new logical closure relative to the explicitly imported base; independent Clean EMPTY-base recheck is a separate result. Generated `_unsafe_rec` executable siblings are classified and excluded from logical proof evidence, and any unsafe/partial dependency in the new logical closure is refused. No generated machine implementation correctness is inferred from the logical proof.
