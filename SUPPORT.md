# Support

## Where to ask

Use this repository's [GitHub Issues](https://github.com/alabsystems/trust-ir/issues)
for bug reports, feature requests, usage questions, and packaging problems.

A useful report includes:

- the TrustIr commit or package version, Rust version, operating system, and
  architecture;
- the exact command or API call and selected Cargo features;
- the artifact format and the smallest input that reproduces the behavior;
- expected and actual output, including the complete diagnostic;
- for proof problems, the evidence kind, claimed authority level, and exact
  validation or lineage gate that was run.

Please remove secrets, personal paths, and proprietary source from public
reproducers.

## Security reports

Do not report suspected vulnerabilities or silently overstated proof authority
in a public issue. Follow the private process in [`SECURITY.md`](SECURITY.md).

## Expectations

Support is best-effort. There are no response-time guarantees or formal
support agreements.
