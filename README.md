# trust-ir

**Represent programs. Carry proofs. Make handoffs checkable.**

A typed, proof-carrying mid-level intermediate representation in Rust, designed as a shared IR for verifiable compiler and verification tooling. TrustIr is the interchange format the rest of the stack hands proofs across.

## Status

Public release in preparation. TrustIr is the root of the publication order — the first verification component scheduled to go public.

This repository is the **public release tier** for `trust-ir`. Development happens in a
private repository; public snapshots are promoted here as reviewed releases tagged
`v<major>.<minor>.0`. See the publication engine's `VERSIONING.md` for the scheme.
